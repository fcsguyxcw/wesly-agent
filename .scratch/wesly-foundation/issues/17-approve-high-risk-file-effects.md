# 17 — 审批高风险文件副作用

**What to build:** 当 Agent 需要创建、删除、移动、重命名、批量修改、二进制修改或触及敏感及工作区外目标时，Wesly 展示规范化操作并只在用户本次明确允许后执行。

**Blocked by:** 16 — 用可审查补丁修改已观察文件

**Status:** ready-for-agent

- [ ] 审批展示操作、参数、解析目标、原因、影响范围和工作区。
- [ ] 用户可选择本次允许或拒绝，不创建持久信任规则。
- [ ] 拒绝返回结构化 `permission_denied`，允许 Agent 调整方案。
- [ ] 无法规范化、特殊文件、凭据位置或不可验证的不可逆操作默认拒绝。
- [ ] 每个高风险文件效果均有真实临时文件系统的允许和拒绝测试。
