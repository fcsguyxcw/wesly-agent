**What to build:** 当 Agent 需要创建、删除、移动、重命名、批量修改、二进制修改或触及敏感及工作区外目标时，Wesly 展示规范化操作并只在用户本次明确允许后执行。

**Status:** resolved

- [x] 用户可选择本次允许或拒绝，不创建持久信任规则。
- [x] 拒绝返回结构化 `permission_denied`，允许 Agent 调整方案。
- [x] 无法规范化、特殊文件、凭据位置或不可验证的不可逆操作默认拒绝。

## Implementation result

- 新增不可变 `PreparedOperation` 与规范化文件效果类型；操作指纹绑定工具参数、解析后的真实目标、内容哈希、目标前置哈希、原因和工作区。
- 新增 `apply_file_operations`，覆盖文本创建/覆盖、二进制覆盖、删除、移动、重命名、独立文件批量写入、敏感配置和工作区外效果；所有有效请求均逐次询问。
- CLI 审批展示操作、脱敏参数、解析目标、原因、影响范围、敏感性、工作区和指纹，只接受“本次允许”或拒绝；审批对象执行或拒绝后不可重放，不建立会话或持久信任。
- 拒绝返回结构化 `permission_denied` 工具结果，Agent 继续下一模型轮次；审批期间 Ctrl+C 以 `interrupted` 停止且不产生副作用。
- 凭据文件及 `.ssh`/`.aws`/`.azure`、版本控制目录、特殊文件、硬链接、重叠目标、缺少可验证前置状态，以及包含删除或移动的不可协调批量操作默认拒绝。
- 真实临时文件系统测试分别覆盖创建、删除、移动、重命名、批量修改、二进制修改、敏感配置和工作区外目标的拒绝与本次允许路径；完整测试为 `80 passed, 2 skipped`，严格 mypy 检查通过。
- Ticket 18 继续负责批准后、真正执行前的路径、类型、哈希和作用域漂移重新验证，本票未提前扩展该边界。
