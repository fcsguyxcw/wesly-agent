# 12 — 让 Agent 自主列出工作区目录

**What to build:** 当回答任务需要仓库结构时，模型可以请求列出工作区目录；Wesly 校验目标、自动允许安全的工作区内只读操作、执行真实文件系统访问，并把结果送回模型继续回答。

**Blocked by:** 11 — 建立可直接回答的 CLI Agent

**Status:** resolved

- [x] 模型能够通过内部工具调用契约请求列目录，并在后续模型轮次收到结构化结果。
- [x] 工具调用依次通过工具存在性、JSON、参数模式、权限和执行校验。
- [x] 普通工作区目录可自动读取，越界路径和特殊目标拒绝执行。
- [x] CLI 显示安全目标、成功或失败状态，且不输出不必要的目录内容。
- [x] 轮次和工具计数被记录并受默认硬限制约束。
- [x] 测试使用真实临时目录覆盖成功、非法参数、未知工具和路径逃逸。

## Implementation result

- Wesly 现在支持分页的 `list_workspace` 工具、多轮模型—工具循环和累计 usage/调用计数。
- 工作区路径按解析后的真实目标授权；越界、未知工具、非法 JSON 和非法参数均转为结构化工具失败，不执行文件系统访问。
- CLI 仅显示转义后的工具名、目标和状态，目录内容只作为不可信工具结果返回模型。
- 严格类型检查通过；完整测试为 `23 passed, 1 skipped`。跳过项是当前 Windows 权限不允许创建目录符号链接，普通 `..` 路径逃逸拒绝测试已通过。
