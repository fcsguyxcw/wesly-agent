# 12 — 让 Agent 自主列出工作区目录

**What to build:** 当回答任务需要仓库结构时，模型可以请求列出工作区目录；Wesly 校验目标、自动允许安全的工作区内只读操作、执行真实文件系统访问，并把结果送回模型继续回答。

**Blocked by:** 11 — 建立可直接回答的 CLI Agent

**Status:** ready-for-agent

- [ ] 模型能够通过内部工具调用契约请求列目录，并在后续模型轮次收到结构化结果。
- [ ] 工具调用依次通过工具存在性、JSON、参数模式、权限和执行校验。
- [ ] 普通工作区目录可自动读取，越界路径和特殊目标拒绝执行。
- [ ] CLI 显示安全目标、成功或失败状态，且不输出不必要的目录内容。
- [ ] 轮次和工具计数被记录并受默认硬限制约束。
- [ ] 测试使用真实临时目录覆盖成功、非法参数、未知工具和路径逃逸。
