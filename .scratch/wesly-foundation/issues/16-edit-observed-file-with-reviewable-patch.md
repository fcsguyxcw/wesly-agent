# 16 — 用可审查补丁修改已观察文件

**What to build:** Agent 可以修改已读取的普通工作区文本文件；执行前向用户展示差异，并以最新观察哈希保护目标，通过有界补丁和原子替换完成写入。

**Blocked by:** 15 — 完成只读仓库调查切片验收

**Status:** ready-for-agent

- [ ] 成功读取文件后记录真实磁盘哈希，修改请求携带该版本前置条件。
- [ ] 普通、非敏感、已存在的单文件修改在前置条件成立时可自动执行。
- [ ] 执行前展示明确差异，写入采用补丁或原子替换。
- [ ] 成功修改后重新读取磁盘哈希，并将新哈希作为最新观察版本。
- [ ] 哈希冲突不覆盖用户变更，而是产生明确失败并要求重新调查。
- [ ] 临时真实文件系统测试覆盖成功写入、冲突、半写入防护和历史哈希保留。
