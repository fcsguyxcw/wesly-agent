# 20 — 根据验证结果继续修复

**What to build:** Agent 能在修改后运行获批验证，理解失败输出，再次调查和修改，直至验证通过或达到明确限制，从而形成首个完整仓库级软件工程闭环。

**Blocked by:** 19 — 经逐次审批运行命令

**Status:** ready-for-agent

- [ ] 模型在后续轮次收到结构化命令结果并能据此修改方案。
- [ ] 一次任务可完成调查、修改、验证失败、再次修改和验证成功。
- [ ] 每次新命令仍独立审批，Agent 迭代不能扩大已批准范围。
- [ ] 达到循环、工具、命令输出或上下文限制时准确停止。
- [ ] CLI 最终报告变更证据、验证结果、运行统计和未完成原因。
- [ ] 端到端测试以真实临时仓库证明修复闭环，无人工代改代码。
