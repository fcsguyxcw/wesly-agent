# 18 — 执行前重新验证已批准操作

**What to build:** 用户批准只绑定当时看到的精确操作；在真正产生副作用前，Wesly 重新验证路径、哈希、目标类型和作用域，阻止审批后发生的替换或漂移。

**Blocked by:** 17 — 审批高风险文件副作用

**Status:** ready-for-agent

- [ ] 审批绑定规范化操作指纹，任一参数或效果变化都触发重新评估。
- [ ] 执行前重新解析目标并验证全部前置条件。
- [ ] 符号链接替换、目标类型变化和文件哈希变化不会沿用旧审批。
- [ ] 权限策略异常、审计失败、审批超时或中断均默认拒绝。
- [ ] 并发漂移测试证明未授权副作用没有发生且事件顺序可审计。
