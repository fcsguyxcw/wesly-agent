# 13 — 完成搜索、读取与文件证据闭环

**What to build:** Agent 可以在真实仓库中连续搜索文本、读取所需文件范围，并依据实际观察过的路径回答问题；大结果通过显式分页继续获取，不能静默截断。

**Blocked by:** 12 — 让 Agent 自主列出工作区目录

**Status:** resolved

- [x] 模型可以在一次任务中组合列目录、搜索和读取多个工具轮次。
- [x] 搜索和读取结果包含返回范围、截断状态和下一页游标。
- [x] 超大单页返回明确错误，不把残缺数据伪装为完整结果。
- [x] 最终答案声称引用文件时，引用路径必须有本次运行的真实工具证据。
- [x] 文件缺失、解码失败、读取失败和越界链接作为可理解的工具结果返回。
- [x] 组件测试和 CLI 端到端测试覆盖顺序调用、单轮多工具和无证据引用失败。

## Implementation result

- 新增分页 `search_text` 与 `read_file`，并统一返回范围、`truncated` 和 `next_cursor`；超过 32 KiB 的单页以 `tool_result_too_large` 明确失败。
- 搜索按稳定路径顺序扫描 UTF-8 普通文件，跳过依赖、缓存、版本控制和凭据位置；解码、读取和权限问题以结构化错误或警告返回。
- 最终文件引用使用 `[[workspace/relative/path]]`，Agent 只接受本次成功搜索或读取产生的真实文件证据，并由 CLI 单独显示引用证据。
- 严格类型检查通过；完整测试为 `36 passed, 1 skipped`。跳过项仍是当前 Windows 权限不允许创建目录符号链接，普通路径逃逸拒绝测试已通过。
