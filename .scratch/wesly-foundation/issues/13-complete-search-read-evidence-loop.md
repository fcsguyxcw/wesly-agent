# 13 — 完成搜索、读取与文件证据闭环

**What to build:** Agent 可以在真实仓库中连续搜索文本、读取所需文件范围，并依据实际观察过的路径回答问题；大结果通过显式分页继续获取，不能静默截断。

**Blocked by:** 12 — 让 Agent 自主列出工作区目录

**Status:** ready-for-agent

- [ ] 模型可以在一次任务中组合列目录、搜索和读取多个工具轮次。
- [ ] 搜索和读取结果包含返回范围、截断状态和下一页游标。
- [ ] 超大单页返回明确错误，不把残缺数据伪装为完整结果。
- [ ] 最终答案声称引用文件时，引用路径必须有本次运行的真实工具证据。
- [ ] 文件缺失、解码失败、读取失败和越界链接作为可理解的工具结果返回。
- [ ] 组件测试和 CLI 端到端测试覆盖顺序调用、单轮多工具和无证据引用失败。
