# 27 — 建立可重复的正式评测框架

**What to build:** Wesly 可以在冻结的仓库和任务合同上运行正式评测，保存不可变、脱敏且可复查的结果；首批两个仓库理解任务验证只读调查能力。

**Blocked by:** 26 — 完成 Windows 日常使用体验

**Status:** ready-for-agent

- [ ] 任务合同固定仓库、提交、提示、准备、检查、禁止变更、验证和预算。
- [ ] 运行记录保存 Wesly 与模型版本、attempt、检查结果、用量、差异和日志资产。
- [ ] 结果只使用 `pass`、`fail`、`blocked` 或 `invalid`。
- [ ] 供应商瞬态故障创建新 attempt，不删除或覆盖旧记录。
- [ ] 两个仓库理解任务在冻结环境中可重复执行。
- [ ] 评测产物不包含密钥或与任务无关的源代码。
