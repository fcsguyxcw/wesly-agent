# 25 — 加固审计和失败关闭行为

**What to build:** Wesly 的模型、工具、权限、审批和恢复行为形成完整且脱敏的审计链；任何安全关键组件无法确定结果时都停止副作用并留下可诊断失败。

**Blocked by:** 24 — 检测工作区漂移并协调恢复

**Status:** ready-for-agent

- [ ] 权限评估、审批请求、决定、执行开始和执行结果均有顺序事件。
- [ ] API key、凭据、隐藏思考和不必要文件内容不会进入日志或数据库。
- [ ] 未知工具、未知能力、策略异常、审计失败和恢复异常默认拒绝。
- [ ] 预期工具失败与编程错误、进程故障明确分流。
- [ ] 故障注入测试证明审计不完整时不会产生未记录副作用。
