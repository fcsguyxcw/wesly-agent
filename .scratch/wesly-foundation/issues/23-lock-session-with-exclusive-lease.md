# 23 — 用独占租约锁定执行中的 Session

**What to build:** 同一 Session 同时只能由一个 Wesly 进程继续执行；只读查看不加锁，恢复和修改状态时必须持有带心跳的独占租约。

**Blocked by:** 21 — 持久化并恢复任务 Session

**Status:** ready-for-agent

- [ ] 执行租约记录唯一所有者、进程、获取时间、心跳和过期时间。
- [ ] 活跃租约阻止第二个进程恢复同一 Session。
- [ ] 约 60 秒无心跳后允许显式警告式接管，不静默抢占。
- [ ] 列出和查看 Session 不需要获取执行租约。
- [ ] 多进程或独立数据库连接测试覆盖竞争、心跳、过期和接管。
